# Australian guide topic coverage

Use this map to find an Australian Accounting Skills workpaper for an OpenAccountants topic. A topic match shows where to start. Rule coverage, calculator results and professional review status need separate verification.

The 21 November 2026 snapshot has 71 guides in the [canonical Australian source tree](https://github.com/openaccountants/openaccountants/tree/d5f956217b4bf67b29910cdae6052ef80fe2a32a/skills/australia) and 62 in the [fork's country tree](https://github.com/ryanduguid/openaccountants/tree/f0a73a1588aa976941e9d03fe3f228f7283304e0/skills/international/australia) and [Australian orchestrators](https://github.com/ryanduguid/openaccountants/tree/f0a73a1588aa976941e9d03fe3f228f7283304e0/skills/orchestrator). The counts exclude each tree's bibliography and include both orchestrators. The 75 distinct filenames are mapped below. Where a topic has multiple guide versions, use the source and year applicable to the work.
