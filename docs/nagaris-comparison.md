# Ask Nagaris skill list comparison

Sixteen new skills and 5 extended skills cover the in-scope topics on the Ask Nagaris public skill list that this repository lacked. A seventeenth new skill in the same change, `au-director-penalty-review`, comes from this repository's own gap list rather than the Nagaris page. On 11 November 2026 `au-main-residence` and `au-share-buy-back` were added for 2 topics this table had recorded as covered by review facts only and as not adopted. Every other topic is either already covered here or is outside the repository's preparation-only accounting boundary, as the table below records.

Comparison date: 2 November 2026. Source: the public page [Ask Nagaris skills: the full list](https://nagaris.com/ask-nagaris-skills), which names 79 skills with a one-line description each, grouped by kind of work, although its introduction says 'more than 80'. Accounting-skills base: `f7e8c38`. The page publishes no skill content, so only the topics were used. All workflow text, sources and validation cards were written independently for this repository from Australian primary sources read on 2 November 2026; no Nagaris text was copied. Topic labels below are this repository's own summaries, not the page's wording.

## Verification and limits

The new skills follow the existing format: inputs, workflow, hand-off, the shared source and review boundary, a primary-source starting point and a discovery-only `sources.json`. Ryan Duguid accepted the fetched readings of those records on 2 November 2026 without recording a current-law fact; records that could not be fetched still await human source review. Each new skill and each extension has at least one fabricated validation card. Their task-only observations on 2 November 2026 led to corrections in 10 of the skills, and Ryan Duguid confirmed a pass for each card on 2 November 2026 ([docs/EVAL.md](EVAL.md)). No rate, threshold, fee or due date was added to skill prose. This comparison does not assess the quality of the Nagaris product, which this repository cannot inspect.
